# DCM Team Skills

Machine-readable best-practice files for AI coding agents. **The source files are shared via git;
each teammate generates their local agent copies by running the sync script.**

## Team skills (5 — canonical)

Load **dcm-testing** when writing or fixing tests.

| Skill | Role | When agent loads |
|-------|------|------------------|
| **`dcm-python`** | FastAPI, pytest, ruff, mypy, collectors, API Gateway checklist | Backend / DataEng Python |
| **`dcm-react`** | React, TanStack Query, Vitest, ESLint, routing, a11y | Frontend TypeScript |
| **`dcm-verify`** | Lint → types → tests → build — **exit 0 before "done"** | Every implement / pre-PR |
| **`dcm-testing`** | Unit vs route/component vs regression — **what test to add** | Writing tests, bug fix, implement |
| **`dcm-uc-validator`** | Unity Catalog explore + validate UI/maquette data refs vs UC | Data existence checks, page/maquette vs UC |

Style: compatibility matrix, Do/Don't, anti-patterns, quick reference.

## Where files live

| Location | Git | Purpose |
|----------|-----|---------|
| `spec-kit-dcm-workflow/skills/dcm-*/SKILL.md` | ✅ tracked | **Source of truth** — edit here, commit here |
| `.claude/skills/dcm-*/SKILL.md` | ❌ gitignored (`.claude/`) | Local copy generated by sync — Claude Code reads it |
| `.agents/skills/dcm-*/SKILL.md` | ❌ gitignored (`.agents/skills/*`) | Local copy generated by sync — Copilot reads it |
| `.github/agents/dcm-*.agent.md`, `.github/prompts/dcm-*.prompt.md` | ❌ gitignored | Generated by sync — do not commit |

**Only the source is versioned.** A plain `git pull` gives a teammate the updated
`spec-kit-dcm-workflow/skills/` files and nothing else — the copies the agents actually read are
regenerated locally by `sync-dcm-extension.sh` (or `install.sh`, which calls it).

## Workflow — update a skill

```bash
# 1. Edit source
vim spec-kit-dcm-workflow/skills/dcm-verify/SKILL.md

# 2. Commit the source (the only tracked location)
git add spec-kit-dcm-workflow/skills/
git commit -m "docs(skills): update dcm-verify gates"
git push

# 3. Regenerate local copies (.claude/skills, .agents/skills, .github/agents)
./spec-kit-dcm-workflow/scripts/sync-dcm-extension.sh
```

## Workflow — after a pull (every dev, every machine)

```bash
git pull
./spec-kit-dcm-workflow/scripts/sync-dcm-extension.sh   # MANDATORY: regenerates local skills
```

## Per host

| Host | Reads | Note |
|------|-------|------|
| Claude Code | `.claude/skills/dcm-*/SKILL.md` | `/speckit.dcm.implement` and `/speckit.dcm.review` name the skill to load |
| Copilot (VS Code) | `.agents/skills/dcm-*/SKILL.md` | also `/dcm-python`, `/dcm-react` as slash agents via `.github/agents/` |
| Cursor | `.cursor/skills/` or ask to load the skill | Same source after sync / copy |

Both trees only exist after a sync — a missing skill means the script was not re-run.

## Spec-kit integration

| Command | Skills |
|---------|--------|
| spec-kit `implement` step, task T00X | domain skill + **`dcm-testing`** (if tests) + **`dcm-verify`** before `[x]` |
| `/speckit.dcm.review` | `scripts/dcm-review.sh` + domain skill + verify checklist |
| Extension commands | generated from `commands/*.md` by sync — they are slash commands, not skills |
