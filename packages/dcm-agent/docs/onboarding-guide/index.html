Introduction

Ce guide accompagne l'onboarding d'une Landing Zone cliente dans Data Connect Monitoring (DCM).

Agent vs guide : l'agent @dp-dcm-lz-client exécute les commandes. Ce guide explique où vous en êtes et qui fait quoi.
